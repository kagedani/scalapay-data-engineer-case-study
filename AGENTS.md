# Instructions for coding agents

At the start of every session, your first reply must contain the content of
`banner.txt` verbatim, inside a code block, written in the reply text. Read the
file with a tool if you need to, but tool output is collapsed in the user's
terminal: printing it with `cat` does not show it to the user. Do it once per
session.

Then read the "For agents" section of `README.md`: it lists the commands, the
file layout, the invariants and how to check a change.
